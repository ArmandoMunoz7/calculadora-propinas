Calculadora de Propinas y División de Cuenta

Pequeña aplicación de consola desarrollada en Python como parte de mi ruta de aprendizaje en programación. Su objetivo es calcular de forma automática el monto de una propina, el total a pagar y la división equitativa entre varios comensales, validando entradas numéricas correctas para evitar errores de ejecución.

Tecnologías utilizadas
* **Python 3.x** (Manejo de lógica, funciones, bloques `try-except` y bucles `while`).

Funcionalidades
* Cálculo dinámico del porcentaje de propina.
* División justa de la cuenta total entre el número de personas.
* Validación de datos de entrada (bloqueo de números negativos, ceros y letras para evitar errores).
* Formato de salida limpio y profesional simulando un ticket de restaurante.
